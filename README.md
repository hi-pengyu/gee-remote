# 遥感自动化管理系统

一套面向农业的遥感监测与作物参数反演平台。用户在 Web 端圈定地块或区域、选定日期，系统自动从 Google Earth Engine 获取 Sentinel-2 卫星影像，在本地运行机器学习模型反演多项作物长势与养分指标，输出数值结果与彩色专题图。

整个流程无人值守：影像下载 → 特征提取 → 模型预测 → 结果落库 → 专题图生成 → 通知业务方，全部由异步任务队列串联。

---

## 功能

### 一、地块与区域管理

- **地块管理**：地块的新增、编辑、删除与列表查询，维护地块边界与作物归属；可查询某地块历史上有哪些可用的卫星影像日期。
- **行政区管控**：以行政区划为单位组织监测范围，支持查看各行政区下的地块统计。
- **自定义区域**：支持按区域名称、缓冲区半径、优先级维护自定义监测区域，作为行政区划之外的补充。
- **作物类型字典**：内置 8 种作物及其生育期监测窗口，用于按作物匹配监测时段。

| 作物 | 代码 | 监测窗口 |
|---|---|---|
| 玉米 | corn | 04-01 ~ 09-30 |
| 水稻 | rice | 05-01 ~ 10-31 |
| 小麦 | wheat | 10-01 ~ 次年 06-30 |
| 大豆 | soybean | 05-01 ~ 09-30 |
| 棉花 | cotton | 04-01 ~ 10-31 |
| 花生 | peanut | 04-15 ~ 09-15 |
| 油菜 | rapeseed | 09-01 ~ 次年 05-31 |
| 马铃薯 | potato | 03-01 ~ 07-31 |

### 二、遥感影像获取

- **按需下载**：提交 AOI 坐标与目标日期，自动检索并下载 Sentinel-2 影像，支持设置时间搜索窗口与云量约束。
- **影像日期查询**：查询指定区域在时间范围内有哪些可用影像过境日期，便于挑选用图时相。
- **瓦片网格缓存**：以网格瓦片为单位缓存已下载的影像。相同或相邻区域再次请求时直接命中缓存，避免重复向 GEE 取数；支持缓存统计、手动预热、过期瓦片刷新与定期清理。
- **下载区域优化**：按日期批量计算最优下载区域，去重合并重叠范围后再触发批量下载，减少无效请求；支持保存计算历史并回溯查看。
- **并发控制**：以信号量限制同时向 GEE 发起的请求数，超出部分自动排队，避免触发平台侧限流。
- **服务账号池**：维护多个 GEE 服务账号并统一调度，实时展示各账号的健康状态、当前并发任务数与累计任务量，按优先级分配请求；异常账号可一键标记恢复或停用，避免单账号配额耗尽导致监测中断。

### 三、作物参数反演

模型在本地运行，不依赖外部预测接口。覆盖作物长势与养分两大类共 7 项：

| 代码 | 指标 | 类别 | 单位 |
|---|---|---|---|
| `zg` | 株高 | 长势 | cm |
| `agb` | 地上生物量 | 长势 | g/m² |
| `hsl` | 叶绿素含量 | 长势 | mg/g |
| `spad` | 叶绿素相对值（SPAD） | 长势 | SPAD |
| `n` | 氮含量 | 养分 | % |
| `p` | 磷含量 | 养分 | % |
| `k` | 钾含量 | 养分 | % |

每个指标由独立模型反演，输入为 Sentinel-2 多光谱波段及由此派生的植被指数。单个指标或整组指标可在同一次请求中完成。

### 四、专题图可视化

- 预测完成后自动为每个指标生成彩色专题图，无需额外触发。
- 每个指标配有独立的 5 级调色板（低 / 较低 / 正常 / 较高 / 高），贴合各自的数值语义与视觉习惯。
- 分级阈值支持**分位数法**与**等比例法**两种方式，可按指标配置分级比例。
- 结果同时提供 TIF 栅格与 JSON 数值两种形态，TIF 亦支持按上述分级规则重新上色输出。

### 五、应用接入与回调

- **应用管理**：为每个接入方创建独立应用，分配 API Key，支持随时重新生成密钥。
- **Webhook 回调**：提交任务时携带回调地址，任务完成或失败后系统主动推送结果，接入方无需轮询。
- **对象存储**：预测结果与影像可上传至对象存储，回调中返回可访问地址。

### 六、任务、结果与统计

- **任务中心**：提交、查询、取消任务，实时回看每个任务的执行状态、当前步骤与进度。
- **结果查询**：按任务查看预测结果明细与各指标的预测值。结果详情分四段呈现：基本信息、缓存信息（命中的瓦片数量与瓦片 ID）、数据信息（总像素数、有效像素数、文件名、是否过期）、模型预测结果（各指标专题图与分级颜色占比）。
- **导出**：任务列表与结果列表均支持导出为表格文件。
- **统计看板**：仪表盘汇总、指标趋势曲线与处理性能统计，趋势支持按 7 / 30 / 90 天切换。

### 七、精细化管控

按策略暂停或恢复监测，粒度可选**行政区**、**自定义区域**或**单个地块**，并可按作物代码筛选，附加原因备注。适用于休耕、征地、数据异常等需要临时停止监测的场景，同时提供总地块 / 监测中 / 已暂停的数量概览与暂停清单。

### 八、自动化与运维

- **每日更新**：定时触发监测更新，可指定单个应用或批量更新全部启用的应用。
- **缓存巡检**：定期检查缓存体积并生成报告，超限自动告警。
- **僵尸任务清理**：回收长时间未完成的任务及其占用的资源。
- **锁与信号量维护**：自动清理残留的 Redis 锁，支持手动重置信号量并查看其状态。
- **健康检查**：提供服务健康状态与队列积压情况查询。
- **配置热管理**：GEE 相关配置以键值方式集中管理，按 gee / storage / api / oss / redis / celery / tile 等分组检索，支持在线修改并热重载，调整参数无需重启服务。

## 脚本工具集（gee-简单版）

除完整的前后端系统外，另附一套轻量脚本工具，用于离线处理与验证，不依赖服务端：

- **GEE 取数与上传**：直接调用 Earth Engine 拉取影像，并将产物上传至对象存储。
- **TIF 上色**：将预测结果 TIF 按分位数或等比例规则上色，可输出图片，也可输出带颜色表的 TIF。
- **JSON 转 TIF**：把预测结果的 JSON 栅格数据还原为带地理坐标的 GeoTIFF。
- **TIF 转 CSV**：将影像波段提取为表格，供模型训练或外部接口调用。
- **矢量处理**：SHP 与 GeoJSON 互转、属性导出，以及从 PostGIS 读取地块生成 MVT 瓦片。
- **坐标转换**：坐标系与几何数据的批量转换。
- **接口调用示例**：演示如何携带 API Key 调用预测接口。
