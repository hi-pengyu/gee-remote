## 🎯 使用说明

### 1. 创建地块

1. 点击"新增"按钮
2. 填写基本信息（应用、名称、几何信息）
3. **选择作物类型**（可选）- 系统会自动填充监测周期
4. **输入行政区代码**（可选）- 留空则根据坐标自动识别
5. **调整监测周期**（可选）- 格式：MM-DD
6. **设置自动更新**（默认开启）
7. 点击"确定"提交

**示例：**
```
应用：测试应用
地块名称：河南玉米地块001
几何信息：{"type":"Polygon",...}
作物类型：玉米 → 自动填充 04-01 ~ 09-30
行政区代码：（留空，自动识别）
自动更新：开启
```

### 2. 切换监测状态

1. 在地块列表中找到目标地块
2. 点击"监测状态"列的开关
3. 确认操作
4. 系统自动更新状态

**效果：**
- 关闭后，该地块不参与每日自动更新
- 开启后，恢复自动更新

### 3. 行政区管控

1. 点击"行政区管控"按钮
2. 在对话框中选择"暂停管理"标签
3. 输入行政区代码（如：41 代表河南省）
4. 输入暂停原因
5. 点击"查看影响范围"预览
6. 确认暂停

**效果：**
- 该行政区内所有地块的监测状态被关闭
- 每日自动更新时自动跳过这些地块

### 4. 恢复行政区

1. 在行政区管控对话框中选择"暂停列表"标签
2. 找到要恢复的行政区
3. 点击"恢复监测"按钮
4. 确认操作

## 🐛 常见问题

### Q1：行政区显示"未识别"？

**原因：** 后端未配置高德API或PostGIS数据

**解决：**
1. 检查后端是否配置了高德地图API Key
2. 或检查是否导入了行政区边界数据
3. 手动输入行政区代码

### Q2：监测状态开关点击无反应？

**原因：** 后端API未启动或权限不足

**解决：**
1. 检查后端服务是否运行
2. 检查浏览器控制台是否有错误
3. 检查用户是否有权限

### Q3：作物类型选择后监测周期没有自动填充？

**原因：** watch监听可能未生效

**解决：**
1. 检查浏览器控制台是否有错误
2. 尝试刷新页面
3. 手动输入监测周期

### Q4：行政区管控对话框打开报错？

**原因：** RegionControlDialog组件未正确导入

**解决：**
1. 检查组件文件是否存在
2. 检查import路径是否正确
3. 检查ref引用是否正确
