## 📊 分级比例配置

### 第一组：15%-20%-30%-20%-15%
- **n** (氮含量)
- **p** (磷含量)
- **k** (钾含量)
- **zg** (株高)

**阈值示例** (分位数法):
```
1级 (低, 15%):    < 分位数0.15
2级 (较低, 20%):  分位数0.15 - 0.35
3级 (正常, 30%):  分位数0.35 - 0.65
4级 (较高, 20%):  分位数0.65 - 0.85
5级 (高, 15%):    > 分位数0.85
```

- **agb** (生物量)
- **hsl** (叶绿素)
- **spad** (SPAD值)

**阈值示例** (分位数法):
```
1级 (低, 15%):    < 分位数0.15
2级 (较低, 20%):  分位数0.15 - 0.35
3级 (正常, 40%):  分位数0.35 - 0.75
4级 (较高, 15%):  分位数0.75 - 0.90
5级 (高, 10%):    > 分位数0.90
```

## 🔧 如何修改配置

### 修改分级比例

编辑 `app/services/visualization_service.py` 中的 `MODEL_PROPORTIONS` 字典：

```python
# 例如：将 n 模型改为 20%-20%-20%-20%-20% (五等分)
'n': [0.20, 0.40, 0.60, 0.80],
```

### 修改调色板

编辑 `MODEL_PALETTES` 字典中对应模型的颜色：

```python
'n': [
    [0, 0, 0, 0],  # 背景透明
    hex_to_rgba("#新颜色1"),  # 1级
    hex_to_rgba("#新颜色2"),  # 2级
    hex_to_rgba("#新颜色3"),  # 3级
    hex_to_rgba("#新颜色4"),  # 4级
    hex_to_rgba("#新颜色5")   # 5级
]
```

### 修改后重启服务

```bash
# 停止并重启 FastAPI 和 Celery Worker
# 修改才会生效
```

## 🎯 设计原理

### 第一组 (15-20-30-20-15)
- **均衡分布**: 适合数值分布较为均匀的营养元素和株高
- **中间集中**: 30%在正常范围，符合大部分作物的生长特征
- **两端对称**: 高低两端各15%，便于识别异常区域

### 第二组 (15-20-40-15-10)
- **强调正常**: 40%在正常范围，生物量和叶绿素大多数区域应该正常
- **减少高值**: 只有10%标记为高值，避免过度渲染高值区域
- **突出低值**: 保持15%低值，便于识别需要关注的区域
